HR FUEL-SMART — Portal Terpisah (Prototipe)
Files: index.html (publik), staff.html (petugas), admin.html (admin pusat), style.css, common.js.
Deploy: unggah SEMUA file ke root repository yang sama. GitHub Pages Settings > Pages > Deploy from a branch > main > /(root).
URL portal: URL utama untuk publik, tambahkan /staff.html untuk petugas dan /admin.html untuk admin.
PENTING: login masih simulasi frontend, bukan autentikasi aman. localStorage membuat data hanya tersimpan di browser/perangkat yang sama. Untuk pemakaian nyata perlu backend, database terpusat, login aman, kontrol akses server, audit log, validasi server, dan penyimpanan bukti. Jangan gunakan data rahasia.
